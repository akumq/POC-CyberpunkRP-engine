## Ce qui a été fait

Code repris de [MrYar07/CyberpunkMP](https://github.com/MrYar07/CyberpunkMP) (branche `coop-2.5`, commits `c96b8c5` et `6fc92e9`), lui-même construit sur [Night City Online](https://github.com/ofmiceandcam98-eng/CyberpunkMP). Les auteurs sont crédités dans les commits.

1. **Fichiers purement moteur repris tels quels** : `code/client/Red` (RedLib de Codeware 1.21.1), `Core/RedLibCompat.hpp`, `Core/Foundation`, `Support`, `Game` (dont `ScriptValidation.h` aux dispositions 2.5 et la swap chain via `GpuApi::SDeviceData`), les fichiers RPC sans logique co-op, `vendor/xmake.lua`.
2. **`vendor/RED4ext.SDK`** : passé sur `MrYar07/RED4ext.SDK`, branche `cpmp-2.5` (`b1e7c36`), le SDK officiel 2.5 fusionné dans le fork CyberpunkMP. API plugin v1.
3. **Fichiers mêlés (moteur et co-op campagne)** : seuls les hunks du commit de portage sont appliqués. Les conflits sont résolus vers le code d'origine, plus les renommages 2.5 (`entityID`, `transformComponent`, `components`, `DynArray::size()`).
4. **Deux erreurs de compilation propres à ce dépôt** :
   - `TagList::Contains("...")` devenu ambigu → `Red::CName` explicite ;
   - `Puppet::moveComponent` absent du SDK 2.5 → vitesse du joueur mesurée par la distance parcourue entre deux envois, bornée à 20 m/s (approche de Night City Online). Même chose pour la vitesse du véhicule (`rigidBody` n'est plus mappé).
5. **Non repris** : co-op campagne, tunnel Steam, installeur, noms au-dessus des têtes, auto-vérification, et le reste des ajouts propres au fork.

## Test en jeu

Mod installé dans `red4ext/plugins/zzzCyberpunkMP`, serveur Docker local (`cyberpunkmp:m0`) lancé, jeu lancé avec `-online -ip 127.0.0.1 -port 11778`.

[RpcValidator] validating 16308 script classes

Le jeu a tourné plus de 30 minutes sans planter. Les exceptions vues dans la sortie Proton sont des exceptions C++ attrapées (code `0x19930520`), pas des plantages. L'écran était verrouillé : le menu n'a pas pu être vu, et aucune partie n'a été chargée, donc pas de connexion au serveur (`OnWorldAttached` absent du log, aucun client côté serveur).

Après le test, le mod a été retiré du jeu (sans `-online`, il charge quand même ses scripts et ses hooks) et les logs archivés hors du dépôt.
